# 🤝 Guia de Contribuição

Obrigado por considerar contribuir com o **Asaas PHP SDK (Não Oficial)**!  
Contribuições são extremamente bem-vindas e ajudam o projeto a evoluir.

Este documento explica como contribuir de forma eficiente e organizada.

---

## 📌 Como Posso Contribuir?

Existem várias formas de contribuir:

- Reportar bugs  
- Sugerir novas funcionalidades  
- Melhorar a documentação  
- Criar testes  
- Otimizar código  
- Implementar novos endpoints da API Asaas  

---

## 🐛 Reportando Bugs

Se encontrar um bug:

1. Verifique se já existe uma issue aberta sobre o problema.
2. Caso não exista, abra uma nova issue contendo:
   - Descrição clara do problema  
   - Passos para reproduzir  
   - Comportamento esperado  
   - Logs relevantes  
   - Versões do PHP, SO e dependências  

Quanto mais detalhado, mais rápido será o diagnóstico.

---

## 💡 Sugerindo Funcionalidades

Para sugerir uma feature:

1. Abra uma issue com o título:  
   **"[Feature] Descrição da funcionalidade"**
2. Explique claramente:
   - Qual necessidade a funcionalidade resolve  
   - Como imagina a API da função/método  
   - Exemplos de uso se possível  

Discussões são bem-vindas antes da implementação.
